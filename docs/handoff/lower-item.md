## `// PORT:` decisions (please record)
1. **Arenas erased** (contract): `alloc(x)` is `x`, and `alloc_from_iter(it.map(f))` is the eager `.map(f)`.
2. **Struct-literal evaluation order.** The generated HIR classes take their arguments in declaration order, but Rust
   evaluates struct literal fields in source order. Every side-effecting field is therefore computed into a local
   first, in Rust source order. Examples: `hir::FieldDef` (`lower_mut_restriction` and `lower_anon_const_*` allocate
   ids before `ty`/`safety` are placed), `Item`, `ForeignItem`, `TraitItem`, `ImplItem` and `Block`.
3. **lib.rs enum values as PORTING §5 literals.** lib.rs's `unknown` types are written as plain literals:
   - fieldless: `"StaticTy"`, `"Fn"`, `"Explicit"`, `"Err"`, `"Yes"`/`"No"`, `"SuperTrait"`;
   - data: `{ $: "Disallowed", _0: .. }`, `{ $: "Universal" }`, `{ $: "OpaqueTy", origin }`, `{ $: "Allowed", _0: map }`,
     `{ $: "Forbidden", _0: reason }`.

   When codegen gives `ImplTraitContext` frozen unit singletons, comparisons must stay by tag (derived
   `PartialEq`), never by `===` on the object. `ResolvingRestrictionKind` is `"Impl"` / `"Mut"`.
4. **The `RelaxedBoundPolicy::Allowed` map** is a `DefIdMap<Span>`, an insertion-ordered `FxIndexMap<DefId, Span>`
   keyed by `DefId` value (plan-m3 D5). The `lower_where_predicate` dedup map is
   `Map<LocalDefId, Map<DefId, Span>>` (the contract signature), and its inner values are `DefIdMap`s.
   - **lower-lib-b**: `validate_relaxed_bound` should only use `Map` methods on it (`get`/`set`/`has`).
5. **`PORT(decls): pending root` views of `unknown` types.**
   - **`PerOwnerLoweringStateView`** (lib-a's `PerOwnerLoweringState`), read through `curr_owner(this)`. It has the
     fields `owner: PerOwnerResolverData`, `attrs: SortedMap<ItemLocalId, readonly attr_ir.Attribute[]>`,
     `bodies: [ItemLocalId, hir.Body][]`, `define_opaque: readonly [Span, LocalDefId][] | undefined`,
     `impl_trait_defs` and `impl_trait_bounds` (arrays, replaced by `[]` on `mem::take`), plus `owner_id()`.
     **lower-lib-a must use these field names and representations**, or adjust the view at merge.
   - **`DelegationResultsView`** (`body_id`, `sig`, `ident`, `generics`; lane lower-delegation).
   - Both views are dropped once codegen set rustc_ast_lowering exists.
6. **The resolver's `MissingLifetimeKind`** (`unknown` in rustc_middle resolve.ts) is cast to
   `hir.MissingLifetimeKind` in `lower_generics`.
7. **`WhereClause::default()`** (derived `Default`) is `new WhereClause(false, [], DUMMY_SP)`, in the test-binder fns.
8. **No clone for `Copy` AST values passed by value** (`FnHeader`, `StrLit`, `Extern`, `Safety`): lowering only
   reads the AST. Explicit `.clone()`s are ported as `clone_<T>`: `Generics` for ty aliases, `DelimArgs`,
   `PathSegment`s, `GenericParam`s, and `WherePredicate`s in `extend_from_slice`.
9. **The Rust `\`-newline string continuations** (two delayed-bug texts and the E0570 help) are rebuilt without
   the newline or the indentation.
10. **`find_attr!` boolean forms** use `find_attr(attrs, k => cond ? null : undefined) !== undefined`, following
    rustc_attr_ir's documented convention.
