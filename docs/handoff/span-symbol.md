## Contract notes
- Interner constructor upstream is `Interner::with_extra_symbols(extra)` (generated by the macro);
  there is no `fresh()` at this pin. span-core's `SessionGlobals::new` should call it.
- Interner methods are `intern_str`/`get_str`/`intern_byte_str`/`get_byte_str` (stub had `intern`/`get`).
- Methods on `Symbol`/`ByteSymbol` live on companion consts: `Symbol.as_str(s)`, `Symbol.intern(..)`.
  Importing `Symbol` shadows the JS global `Symbol` in that module.

## PORT decisions
- Display impls → `display_<Type>(v): string` (no width/fill flags); Debug → `debug_<Type>`.
- `Ident::hash(state)` takes a feed function (no Hasher in src/std).
- Interner keyed by JS strings; non-UTF-8 byte strings keyed by U+DFFF + Latin-1 bytes (no collision
  with valid UTF-8 keys); `get_str` on such an index panics (UB upstream). Arena erased.
- `SymbolIndex::from_u32` assert inlined in `Symbol.new`/`ByteSymbol.new`.
- `sym` = spread of `sym_generated`, then explicit items (shadowing like Rust glob imports).
- `STDLIB_STABLE_CRATES` is a `let` assigned after `sym`.
- `Symbol::stable_cmp` returns -1/0/1, code-point order.
- `to_lowercase`/`to_uppercase` → JS `toLowerCase`/`toUpperCase` (engine Unicode version may differ).
- `usize::MAX` → `Number.MAX_SAFE_INTEGER` (`usize_MAX`, exported from edit_distance.ts).
- `sort_by_words` uses JS default sort; only equality of sorted lists is observed.
