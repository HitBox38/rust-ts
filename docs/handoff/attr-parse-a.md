## PORT decisions (please record)
1. **`ATTRIBUTE_PARSERS`.**
   - The `LazyLock` becomes the accessor `ATTRIBUTE_PARSERS()`, following the `BUILTIN_ATTRIBUTE_SET()` precedent.
   - The `attribute_parsers!` macro is the function `attribute_parsers(list)`. It performs the expansion per parser type, in list order.
   - `thread_local! STATE_OBJECT` is one state object per type; `take()` returns it and stores a fresh `default()`.
   - `BTreeMap<&[Symbol], _>` becomes `Map<string, _>` keyed by `path_key(path)`, which joins the symbol indices with `,`.
2. **Trait tables.**
   - A parser *type* is its trait table, holding its consts and fns. `self` is the first parameter. `Default` is `default()`, which returns a mutable state object that accept fns mutate in place.
   - Generic `Single<T>` / `Combine<T>` / `WithoutArgs<T>` are functions from a table to a table.
   - The list's existential state type is `ErasedAttributeParser = AttributeParser<any>`.
   - `ExpectNameValue` / `ExpectStringLiteral` are per-type tables passed as a trailing argument: `cx.expect_name_value(arg, span, name, ExpectNameValue.ArgParser)`.
3. **Deref chains are written out:** `adcx.ctx`, `cx.shared`, `shared.cx`. The `deref()` / `deref_mut()` fns return those fields.
4. **Field renames for name clashes:**
   - `AttributeParser.{sess_, features_}`; the methods `sess()` and `features()` keep their names.
   - `SharedContext.emit_lint_`.
   - `MetaItemParser.{path_, args_}`.
5. **Methods defined in other files.** `impl AttributeParser` / `impl AcceptContext` blocks in other files are extension modules that augment the class interface. `lib.ts` loads them after `interface.ts` and `context.ts`. Associated fns without `self` that are defined elsewhere are `declare static` members of the `AttributeParser` class.
6. **Macros.**
   - `template!` becomes `template({ Word?, List?, OneOf?, NameValueStr? }, link?)`.
   - `unstable!(feat, notes..)` becomes `unstable(sym.feat, ...notes)`. The macro's compile-time feature-exists check has no runtime counterpart.
   - `AttributeTemplate` is an immutable class that is shared, not cloned; its `Default` is unused at the pin.
7. **Representations.**
   - `PathParser<P: Borrow<Path>>` is one class; `OwnedPathParser` and `RefPathParser` are aliases.
   - `segments()` and `mixed()` are generators.
   - `EmitAttribute` wraps a closure `(dcx, level, sess) => Diag`.
8. **`#[cfg(debug_assertions)]`-only fns are `rustc-skip`:** `check_args_used` (interface.rs:531) and `are_args_checked` (parser.rs:375). Root: please record this as a decision. The precedent is the omitted `#[cfg(debug_assertions)]` code elsewhere.
9. **Imports from rustc_parse.**
   - `PathStyle::Mod` and `ForceCollect::No` are written as the literals `"Mod"` / `"No"`, with type-only imports from `path.gen.ts` / `mod.gen.ts`. `path.ts` is not reachable through `rustc_parse/lib.ts`.
   - `lib.ts` re-exports `Recovery` from `rustc_parse/parser/mod.gen.ts`.

## Contract for attr-parse-b
- **Keep every export name and shape of the stub files.** Fill the files in place, add markers in upstream order, and delete `unported_impl` once no stub uses it.
- **Diagnostics.** Generate `diagnostics.rs` with a `rustc_attr_parsing` codegen set. That needs a `tools/` change: `types.sets.json`, plus typemap entries for `AttrPath`, `AttributeTemplate`, `ParsedDescription` and `Suggestion`.
  - Keep the `X_into_diag` / `X_diagnostic` names.
  - `AttributeParseError`'s manual `impl Diagnostic` must be `AttributeParseError_diagnostic(self)`.
  - `IllFormedAttributeInput.new(suggestions, docs, help)` is a companion fn.
  - `ParsedDescription` stays the string union `"Attribute" | "Macro"`.
- **Parser tables.** Each parser is `export const XParser: <Trait> = { .. }`, where `<Trait>` is the interface in `attributes/mod.ts`.
  - For `SingleAttributeParser`, `NoArgsAttributeParser` and `CombineAttributeParser<Item>`, the provided items (`ON_DUPLICATE`, `SAFETY`, `finalize_check`, `deferred_finalize_check`) come from `<Trait>_provided` helpers in `mod.ts`.
  - Direct `AttributeParser<State>` tables also implement `default()`.
  - `context.ts` imports each parser by its upstream name from its module. `attributes/path.ts` exports `PathParser`, which `context.ts` aliases to `PathAttributeParser`.
- **Calling the context.** From an `AcceptContext` `cx`:
  - errors: `cx.shared.emit_err(..)` and `cx.adcx().expected_list(..)`
  - lints: `cx.shared.emit_lint(lint, X_diagnostic(..), span)`
  - the parser: `cx.shared.cx.sess()`, `.features()`, `.features_option()`
  - target checks: `cx.check_target(..)` / `AttributeParser.check_target(..)`
- **When the stubs are replaced,** run `attr_oracle.test.ts` and remove the PENDING entries that now match. Every list case should then compare against the recorded `AttributeKind` Debug.
