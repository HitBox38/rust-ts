## Generator changes (tools/codegen/types.ts)
1. `stable_hash.json` entries may list `imports: { module: [names] }` (an external alias such as
   `BinOp = Spanned<BinOpKind>` uses fns of two modules).
2. derive(StableHash) on an impl-form bitflags struct (`#[derive(StableHash)] struct MacroKinds(u8)` +
   `bitflags! { impl MacroKinds: u8 }`) hashes the single field (the TS branded number); was an `ERROR:`.
3. Two derived types of one crate with the same name (`ast::LitKind`, `token::LitKind`) get
   `stable_hash_<module>_<T>` (and `<module>_<T>__discriminant`) instead of a duplicate export; references follow.
   Names of all other types are unchanged (every other set regenerates byte-identically).

## `// PORT:` decisions (please record)
1. `Unambig` (`()` / uninhabited `AmbigArg`) is a generic parameter erased to `null` / `never`; `as_unambig_*` /
   `try_as_ambig_*` and the hir/tests.rs transmutes are casts. `Ty<AmbigArg>::peel_refs` (:3227) and `Ty::peel_refs`
   (:3237) are one prototype method (both markers).
2. Field/method name clashes keep the field (it is the generated data) and suffix the method: `GenericArgs::span_ext()`
   -> `span_ext_()`, `PathSegment::args()` -> `args_()`, `FnDeclFlags::splatted()` -> `splatted_()`,
   `FnHeader::safety()` -> `safety_()`. `FnDeclFlags::default()` -> static `default_()` (reserved word in a namespace
   declaration).
3. `FnDeclFlags::set_*(mut self, ..) -> Self` clone the receiver (`clone_FnDeclFlags`) and return the copy (Copy type).
4. Statics on generated classes via `Object.assign` + `declare module` namespaces (`Lifetime.new`, `PathSegment.new`/
   `invalid`, `Generics.empty`, `GenericArgs.NONE`, `AttributeMap.EMPTY`, `OwnerNodes.synthetic`, `FnDecl.dummy`,
   `FnDeclFlags` consts). `GenericArgs.NONE` and `Generics::empty()`'s `NOPE` are frozen shared values.
5. `From` impls are named companion fns: `LifetimeSyntax.from`, `Term.from_Ty`/`from_ConstArg`,
   `OwnerNode.from_Item`/... , `Node.from_OwnerNode`, `HeaderSafety.from`. `Display` impls are `display_<T>(self)`;
   `CoroutineDesugaring`/`CoroutineKind` take `alternate` for `{:#}`.
6. `impl Iterator` results (`Generics::bounds_for_param`, `outlives_for_param`, `UseTree::resolutions`) are arrays
   computed eagerly.
7. `TaggedRef` is the unpacked `{ pointer, tag }` pair (no pointer tagging in TS).
8. `SortedMap`'s `K: Ord` stays a constructor comparator; `default`/`new` take it; HIR maps use `ItemLocalId_cmp`
   (exported by hir.ts). One `SortedMap` class for the whole port now (the definitions.ts stand-in is gone).
9. rustc_hir/lib.ts re-exports stable_hash_impls.ts (`impl StableHash` of a private module are crate-global upstream).
10. Split with hir-visit: the plan lists "the hir.rs fns" under hir-visit and my brief asked for the pure helpers; I took
    every hir.rs fn that does not need intravisit (list above). hir-visit should add only the 4 left.
