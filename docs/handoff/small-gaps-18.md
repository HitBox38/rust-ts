## PORT decisions
1. Struct methods of generated data types are companion consts (`EarlyParamRegion.is_named`, binder.ts precedent); trait
   impls whose method names collide with inherent ones are separate impl objects (`RegionName_EarlyParamRegion`, ...).
2. `impl Elaboratable for X` is the descriptor `Elaboratable_X` (rustc_type_ir elaborate.ts convention).
3. `impl_ref_decodable_into_arena!` impls are `decode_RefDecodable_into_arena` / `decode_RefDecodable_slice_into_arena`
   (generic over the element's decoder); arenas erased.
4. hir_wf_check's fn-local `HirWfCheck` is a class inside the provider; its `loc` is re-matched through a cast so the
   upstream arms stay.
5. `debug_assert_fully_normalized`: `cfg!(debug_assertions)` is false.
