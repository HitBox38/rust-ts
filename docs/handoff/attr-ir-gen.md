# Handoff: attr-ir-gen (wave 8, M2 foundations)

`rustc_attr_ir` types + Debug/Clone/Default/PrintAttribute generated by `tools/codegen/types.ts` (new set
`rustc_attr_ir`), every fn of the crate hand-ported (150/150), Debug/PrintAttribute checked byte-for-byte
against a rustc-dev oracle.

## Pin facts that differ from the brief
- **`hir::Attribute` is `rustc_attr_ir::Attribute` at the pin.** `Attribute` (`Parsed(AttributeKind)` /
  `Unparsed(Box<AttrItem>)`), `AttrItem`, `AttrArgs`, `AttrPath`, `HashIgnoredAttrId` are defined in
  `compiler/rustc_attr_ir/src/attr.rs`; `rustc_hir/src/hir.rs` only has a private
  `use rustc_attr_ir::Attribute;` (plus `AttributeMap`, a HIR-owner map: M3). rustc_attr_parsing does not
  depend on rustc_hir at all. So the "rustc_hir attribute subset" is generated into
  `src/rustc_attr_ir/attr.gen.ts` (mirror rule) and **nothing was written under `src/rustc_hir/`**.
  Decision for root to record: "attr-ir-gen: hir::Attribute/AttrItem/AttrArgs/AttrPath live in
  rustc_attr_ir/src/attr.rs at the pin; generated there, no src/rustc_hir files".
- The crate has 12 source files (+ `attribute_docs.rs`, rustdoc-only, `include!`d by lib.rs: nothing to port).
- `PrintAttribute` is a derive (`rustc_macros/src/print_attribute.rs`) plus hand impls in `pretty_printing.rs`.
- `StableHash` is the pin's name for `HashStable`.

## Generator changes (tools/codegen)
1. **`language_item_table!`** (lang_items.rs:158): `macros.ts` `parseLanguageItemTable` (rows
   `variant, module::name, method, target, generics;`, docs kept) + `parseLanguageItemTableDef` (the enum's
   docs/derives/name from the `macro_rules!` body). types.ts synthesizes the `LangItem` enum item (226 unit
   variants, derives from the macro, per-variant doc `The \`name\` lang item.`), so it gets the normal string
   union + companion + `LangItem_discriminant` (set `discriminant`) + Debug + PrintAttribute. After all items
   of the file it emits `language_item_table` (rows as data; `sym::x` -> `sym.x`, `Enum::V` -> companion
   value, `Enum::V(..)`/`Enum::V { .. }` -> object literals; anything else is an `ERROR:`) and the
   `LanguageItemsGetters` interface (one getter per row). The macro's fns are hand-ported over the rows.
2. **`#[derive(PrintAttribute)]`**: port of `rustc_macros/src/print_attribute.rs` (`print_fields` statement by
   statement: name word, `if (true && !..should_render..) return;`, nbsp/`{`/fields/`}` or popen/pclose,
   `__printed_anything`). Emitted after the type as `export const print_attribute_<T>: PrintAttribute<T>`
   (`// rustc-derive:` comment). Field types: derived items -> `print_attribute_<T>`, references/tuples/`()`
   built in, external types from the new `print_attribute.json` (the impls of pretty_printing.rs). Missing
   impl -> `ERROR:`. Report: `files[].print_attrs`.
3. **`#[derive(Default)]`** (set option `derive_default`, on for rustc_attr_ir only): `default_<T>()`; struct
   fields via typemap `default` rules (added to typemap.json for ints, bool, String, Option, Vec/ThinVec,
   Box (`$e0`), FxIndexMap, Span (`DUMMY_SP`, `default_values`)); enums: the `#[default]` unit variant.
   `#[derive_const(Default)]` (`RtsanSetting`) is not a `derive` and is not generated.
4. typemap `clone_values` (names a clone template needs, imported only where a clone is emitted) — so adding
   the `RustcVersion` clone rule does not add imports to rustc_errors/rustc_lint_defs output.
5. typemap.errors.json: clone rules for `RustcVersion`, `PathBuf` (copy), `NonZero` (transparent).
6. typemap.attr_ir.json: rustc_ast/rustc_span types this set uses; **outward entries** for other sets:
   `rustc_attr_ir::{AttributeKind, Attribute (also rustc_hir::Attribute), AttrItem, AttrArgs, AttrPath}`,
   `rustc_attr_ir::target::Target`. diag_args.json: `Target`, `AttrPath` (into_diag_arg + display),
   `MirDialect`, `MirPhase`.
- Regenerating all 7 sets changes only the rustc_attr_ir files (others byte-identical; checked).

## PORT decisions (please record)
- `PrintAttribute` = per-type table `print_attribute_<T>: PrintAttribute<T>` (`should_render(self)`,
  `print_attribute(self, p)`); generic impls are functions of the argument tables (`print_attribute_Option(t)`,
  `print_attribute_ThinVec(t)`, `print_attribute_FxIndexMap(k, v)`, `print_attribute_tuple([..])`, ...);
  `print_skip!/print_disp!/print_debug!` -> helpers taking the type's Display/Debug, one const per listed type.
- The `language_item_table!` rows are generated data; the macro's fns (`from_u32`, `name`, `from_name`,
  `variant_name`, `target`, `required_generics`, the 226 `LanguageItems` getters) are hand-ported over them.
  `LangItem` methods (incl. weak_lang_items' `is_weak`/`link_name`) live on the `LangItem` companion.
- `impl AttributeKind` of encode_cross_crate.rs: plain functions, spread into the `AttributeKind` companion by
  data_structures.ts. `Attribute`'s inherent + forwarding fns live on an `Attribute` const (no generated
  companion: no unit variants); `AttributeExt.Attribute` is this crate's impl table (rustc_ast pattern).
- rustc_ast does not export `AttributeExt_provided`; attr.ts has a marker-less copy. **Root:** export it from
  rustc_ast/attr/mod.ts and drop the copy (one-line change outside this lane).
- `find_attr!` -> `find_attr(attrs, kind => R | undefined)` in lib.ts (first `Parsed` match wins); `HasAttrs` is
  an interface over the id type.
- `DocCfgHideShow::merge_with(&mut self, ..)` (replaces the whole value) takes a `MutRef<DocCfgHideShow>`.
- Copies of `Copy` objects use `clone_<T>` (`DocCfgHideShowValue` in merge_with, `CanonicalSymbol` in
  get/iter, `StableSince` in stable_since, `Target` in `LangItem::target`).
- `#[derive(Default)]` generated (set option), `default_<T>()`; `MacroUseArgs`' manual `impl Default` is
  `MacroUseArgs.default()`.

## API contract for attr-parse-a / attr-parse-b
Import everything from `src/rustc_attr_ir/lib.ts` (it loads rustc_ast first); `target` / `lang_items` /
`diagnostic` are also namespaces (`import { target } ...` or `./target.ts` directly).
- **Enums with data** (`AttributeKind`, `Attribute`, `AttrArgs`, `InlineAttr`, `ReprAttr`, `IntType`,
  `DeprecatedSince`, `StabilityLevel`, `StableSince`, `UnstableReason`, `MacroUseArgs`, `Target`,
  `MethodKind`, `CguFields`, `PeImportNameType`, `DocCfgHideShow`, `RustcMirKind`, `EiiImplResolution`,
  `Piece`, `FormatArg`, `Predicate`, `Name`, `LitOrArg`, `UnrollAttr`): object literals
  `{ $: "Repr", reprs: [[ReprC, span]], first_span }`, tuple fields `_0, _1`; unit variants are frozen
  singletons on the companion (`AttributeKind.Cold`, `AttrArgs.Empty`, `Target.Fn`) or `{ $: "Cold" }`.
  `pub use ReprAttr::*` -> `ReprRust, ReprC, ReprSimd, ReprTransparent` values.
- **Fieldless enums** are strings: `"Hint"`-style (`OptimizeAttr`, `CoverageAttrKind`, `UsedBy`, `Linkage`,
  `MirDialect`, `MirPhase`, `LangItem`, `CguKind`, `InstructionSetAttr`, `DocInline`, `HideOrShow`,
  `WindowsSubsystemKind`, `RtsanSetting`, `Flag`, `EncodeCrossCrate`, ...), companion `X.V` too.
- **Classes** (structs with inherent fns; `new X(fields in declaration order)`): `AttrPath(segments, span)`,
  `Deprecation(since, note, suggestion)`, `Stability(level, feature)`, `ConstStability(level, feature,
  promotable, const_stable_indirect)`, `PartialConstStability(level, feature, promotable)`,
  `DocCfgHideShowValue(span, value)`, `RustcAutodiff(mode, width, input_activity, ret_activity)`,
  `StrippedCfgItem(parent_scope, ident, cfg)`, `Directive(is_rustc_attr, filters, message, label, notes,
  parent_label)`, `FormatString(input, span, pieces)`, `Filter(span, pred)`, `NameValue(name, value)`,
  `FilterFormatString(pieces)`, `CustomDiagnostic`, `FilterOptions`, `LanguageItems`, `CanonicalSymbols`.
  Statics: `AttrPath.from_ast(path, lower_span)`, `ConstStability.from_partial/unmarked`,
  `DocCfgHideShowValue.new/new_none`, `RustcAutodiff.error/source`, `LanguageItems.new()`,
  `CanonicalSymbols.new()`.
- **Plain structs** are object literals: `AttrItem { path, args, id: { attr_id }, style, span }`, `EiiImpl`,
  `EiiDecl`, `LinkEntry`, `DebugVisualizer`, `DocAttribute` (start from `default_DocAttribute()`),
  `CfgHideShow`, `RustcCleanAttribute`, `RustcCleanQueries`, `UnstableRemovedFeature`, `FormatArgs`,
  `AutoDiffItem`, `CanonicalSymbol`, `DiagnosticItems`.
- `Option<T>` = `T | undefined`, `ThinVec`/`Box<[T]>` = arrays, tuples = TS tuples, `FxIndexMap` = `Map`,
  `PathBuf` = string, `NonZero<u32>` = number, `Box<T>` = `T`.
- Methods: enum methods on companions (`InlineAttr.always(a)`, `OptimizeAttr.do_not_optimize(o)`,
  `AttributeKind.encode_cross_crate(k)`, `Target.from_ast_item(item)`, `Target.name(t)`,
  `StabilityLevel.is_stable(l)`, `UnstableReason.from_opt_reason(r)`, `LangItem.from_name(s)`,
  `Attribute.span(a)` / `Attribute.has_name(a, sym)` / ...); class methods on instances
  (`deprecation.is_in_effect()`, `directive.eval(opts, args)`).
- Derived helpers: `debug_<T>(v, f)`, `clone_<T>(v)`, `default_<T>()` (DocAttribute, Directive,
  CustomDiagnostic, OptimizeAttr, DiagnosticItems), `print_attribute_<T>` (+ `Printer.new()` /
  `p.eof()` from rustc_ast_pretty/pp.ts), `LangItem_discriminant`.
- Diagnostics: `Target_into_diag_arg` / `display_Target`, `AttrPath_into_diag_arg` / `display_AttrPath`,
  `MirDialect_into_diag_arg`, `MirPhase_into_diag_arg` (also wired in diag_args.json for derives).
- Generating rustc_attr_parsing types: typemap.attr_ir.json already maps `rustc_attr_ir::{AttributeKind,
  Attribute, AttrItem, AttrArgs, AttrPath}` and `rustc_attr_ir::target::Target`; add more entries there as
  needed (same file, same shape).
- Not available yet: values of the stand-in types (see above); `LanguageItems::set/from_def_id`.
