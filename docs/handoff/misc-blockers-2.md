## 2. Stable hash of `explicit_clauses_of` values (the async-closure stop)
- **What it needed.** The value type is `ty::GenericClauses<'tcx>` = `{ parent: Option<DefId>, clauses: &[(Clause, Span)] }`.
  That needs `StableHash for Clause`, i.e. `Interned<WithCachedTypeInfo<Binder<PredicateKind>>>` and the whole
  `PredicateKind` closure. All of it is generated; nothing is hand-written.
- **tools/codegen/types.sets.json.**
  - Set `rustc_ty`, `stable_hash_types` gains:
    - `EarlyBinder`, `PredicateKind`, `ClauseKind`;
    - the 14 predicate types they hold: `OutlivesClause`, `RegionEqPredicate`,
      `rustc_type_ir::predicate::RegionConstraint` (by key: `region_constraint::RegionConstraint` is a different
      type), `TraitRef`, `TraitClause`, `ImplPolarity`, `ClausePolarity`, `ProjectionClause`, `NormalizesTo`,
      `HostEffectClause`, `SubtypePredicate`, `CoercePredicate`, `BoundConstness`, `AliasTermKind`;
    - the hand types `Predicate` and `Clause`, with `stable_hash_access` `$v` (their objects carry `.internee`,
      like `Const`).
  - Set `rustc_middle`, `stable_hash_types` gains `rustc_middle::ty::generics::GenericClauses`.
- **tools/codegen/types.ts (generator change, please review).** `shItemName`: an item of the set being generated may
  have no derive in the set and no manual impl. When stable_hash.json has a plain `stable_hash_<T>($v, $hcx, $h[,
  $s0..])` entry for its key, the generator now imports that function. Before, it reported the item missing.
  - Needed because the `rustc_middle` set contains predicate.rs, so `Clause` is an in-set item there. Its impl is
    generated by set `rustc_ty` (`ty_stable_hash.gen.ts`).
  - The type-parameter count must match the template's `$sN` list.
- **tools/codegen/stable_hash.json** gets three entries:
  - `rustc_middle::ty::{,predicate::}Clause` and `Predicate` -> `rustc_middle/ty_stable_hash.gen.ts`;
  - `rustc_type_ir::{,binder::}EarlyBinder` / `rustc_middle::ty::EarlyBinder` ->
    `stable_hash_EarlyBinder($v, $hcx, $h, $s0)`.
