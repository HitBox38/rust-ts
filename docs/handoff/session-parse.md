# Handoff: session-parse (wave 6 porter): rustc_session parse.rs, diagnostics.rs, utils.rs, lib.rs

Branch `lane/session-parse`.

## Pin facts that differ from the brief
- **`ParseSess` is slim at the pin.** It has no `config`, `check_config`, `unstable_features`, `env_depinfo` or
  `file_depinfo`. Those live on `Session` / `config.rs` now.
  - The fields are: `dcx` (private), `edition`, `raw_identifier_spans`, `bad_unicode_identifiers`,
    `source_map` (private), `buffered_lints`, `complete_stmt_exprs_before_bin_op_lookalike`, `gated_spans`,
    `symbol_gallery`, `attr_id_generator`.
  - Every `psess.*` use in upstream `rustc_parse` is covered by these fields: gated_spans, source_map, buffer_lint, dcx,
    complete_stmt_exprs_..., symbol_gallery, attr_id_generator, raw_identifier_spans, edition, dyn_buffer_lint.
- **`feature_err*` and `add_feature_diagnostics*` take `&Session`, not `&ParseSess`.** They live in
  `diagnostics.rs`; parse.rs holds none of them.
  - rustc_parse calls none of them. The parser only records `gated_spans`; rustc_ast_passes reports them.
- **No `config/cfg.rs` types are needed.** `ParseSess` holds none of them, so none were ported. config is left to
  lane session-options.
- **`macros.rs` has no fns.** It holds only the `AllVariants` trait and the derive macro, so no TS file was made.
- **There is no `lint.rs` or `lint/builtin.rs`.** lib.rs has `pub(crate) use rustc_lint_defs as lint;`, which is
  crate-private, so TS modules import `src/rustc_lint_defs` directly.

## Contract: constructing a `ParseSess` (for lanes lexer and parser, and the driver)
```ts
import { ParseSess } from "src/rustc_session/parse.ts";
import type { Session } from "src/rustc_session/lib.ts";
import { AnnotateSnippetEmitter } from "src/rustc_errors/annotate_snippet_emitter_writer.ts";
import { DiagCtxt, DiagCtxtFlags_default } from "src/rustc_errors/lib.ts";
import { FilePathMapping, SourceMap } from "src/rustc_span/source_map.ts";
import { AutoStream, ColorChoice } from "src/vendor/anstream/lib.ts";
import { VecU8, dyn_write } from "src/vendor/anstream/stream.ts";

// Inside create_default_session_globals_then(..) / create_session_globals_then(edition, ..):
// with_dcx reads ExpnId::root().expn_data().edition.
// Test: the emitter writes into a byte buffer.
const sm = SourceMap.new(FilePathMapping.empty());
const buf = new VecU8();
let em = AnnotateSnippetEmitter.new(AutoStream.new(dyn_write(buf), ColorChoice.Never));
em = AnnotateSnippetEmitter.sm(em, sm);
em = AnnotateSnippetEmitter.ui_testing(em, true);
const dcx = DiagCtxt.new(em).with_flags({ ...DiagCtxtFlags_default(), can_emit_warnings: true });
const psess = ParseSess.with_dcx(dcx, sm);        // new TextDecoder().decode(buf.bytes()) = stderr text
// Upstream test helper (stderr, ColorConfig::Auto): ParseSess.new(); ParseSess.emitter_with_note(note)
// Driver: build the emitter as above, but over stderr_destination(color) (rustc_errors/emitter.ts), with the
// session's options (ui_testing, short_message, diagnostic_width, theme, ...); then ParseSess.with_dcx(dcx, sm).
// The driver must drop the DiagCtxt at the end (dcx.inner.drop(): stashed diags, delayed bugs).
```

  - `psess.dcx()` returns a `DiagCtxtHandle`.
  - `psess.source_map()` returns the `SourceMap`.
  - `psess.edition`
  - `psess.gated_spans.gate(sym.x, span)` and `.ungate_last(..)`
  - `psess.raw_identifier_spans.push(span)`
  - `psess.bad_unicode_identifiers` is a `Map<Symbol, Span[]>`.
  - `psess.symbol_gallery.insert(sym, span)`
  - `psess.complete_stmt_exprs_before_bin_op_lookalike` is a `Map<Span, Span>`.
  - `psess.attr_id_generator.mk_attr_id()`
  - `psess.buffer_lint(lint, span, node_id, DecorateDiagCompat | Diagnostic)`
  - `psess.dyn_buffer_lint(lint, span, node_id, (dcx, level) => Diag)`
  - `psess.buffered_lints` is a `BufferedEarlyLint[]`.

## PORT decisions
- **`Session` stand-in.** `Session` is a stand-in interface in `lib.ts`, pending session.rs. It has
  `dcx()`, `unstable_features` and `opts.unstable_opts.ui_testing`, the surface diagnostics.rs reads. The real class
  must satisfy it structurally. Once session.rs is ported, replace the interface with `export * from "./session.ts"`.
- **`dyn_buffer_lint_sess`.** The `&dyn Any` argument is cast to `Session` without a runtime downcast check, since
  there is no Session class yet.
- **Private field names.** The private fields `ParseSess.dcx` and `ParseSess.source_map` are `dcx_` and
  `source_map_`, so the accessor methods `dcx()` and `source_map()` keep their upstream names. The same applies to
  `CanonicalizedPath.canonicalized_`/`original_`; Debug prints the upstream names.
- **Defaults.** `#[derive(Default)]` on `GatedSpans`/`SymbolGallery` becomes `static default()`.
  - `Lock`/`AppendOnlyVec` are the inner values.
  - `Arc<SourceMap>` is the object itself, so `clone_source_map` returns the same object.
- **`Into` conversions.** `impl Into<DecorateDiagCompat>` accepts a `DecorateDiagCompat` or any `Diagnostic`, via
  `DecorateDiagCompat.from`. `impl Into<MultiSpan>` is `IntoMultiSpan` + `into_MultiSpan`.
- **`CFG_VER_DATE` = "2026-10-10".** This is `UPSTREAM.json` `rust.commitDate`. It was verified against the oracle's
  non-ui-testing output "this compiler was built on 2026-10-10". It follows the same pattern as `CFG_RELEASE` in
  rustc_ast/attr/version.ts.
- **`extra_compiler_flags`.** `std::env::args_os()` becomes `process.argv.slice(1)`.
  - `was_invoked_from_cargo` keeps the `OnceLock` as a module-level cache.
- **Session methods in `utils.ts`.** `impl Session` methods of utils.rs are on `Session_utils` (`timer`, `time`)
  until Session is a class.
- **Hand-written types.** `NativeLib` and `CanonicalizedPath` are hand-written, with Debug, because the codegen set
  covers diagnostics.rs only. `NativeLibKind` is an opaque stand-in.
- **rustc_ast imports.** rustc_ast is imported via `rustc_ast/lib.ts` (`ast`, `attr`, `token`), per the recorded
  ast-attr decision.
