# Contract: rustc_span lanes (wave 1)

Three lanes port rustc_span in parallel. Each owns its files; they meet only at these exports.
If you need something not listed, `unported("...")` it and note it in your handoff; root reconciles.

| Export | Defined in (owner lane) | Shape |
|---|---|---|
| `Span` | `src/rustc_span/span_encoding.ts` (span-core) | branded number; `DUMMY_SP` = the dummy span |
| `SpanData` | `src/rustc_span/lib.ts` (span-core) | class `{ lo, hi, ctxt, parent }` |
| `BytePos`, `CharPos`, `RelativeBytePos` | `src/rustc_span/lib.ts` (span-core) | branded numbers + companion helpers |
| `SessionGlobals`, `with_session_globals`, `create_session_globals_then`, `create_default_session_globals_then` | `src/rustc_span/lib.ts` (span-core) | `SessionGlobals.symbol_interner: Interner`, `.hygiene_data: HygieneData`, `.source_map: SourceMap \| undefined` (SourceMap stays `unported` until wave 2) |
| `Edition` | `src/rustc_span/edition.ts` (span-core) | string union |
| `Symbol`, `Ident`, `Interner`, `kw`, `sym`, `sym::integer` etc. | `src/rustc_span/symbol.ts` (span-symbol) | `Symbol` branded number; `Interner.prefill(...)`/`fresh()`; `kw.X`/`sym.x` constants generated by `tools/codegen/symbols.ts` into `src/rustc_span/symbol.gen.ts` |
| `SyntaxContext`, `ExpnId`, `LocalExpnId`, `ExpnData`, `ExpnKind`, `MacroKind`, `Transparency`, `HygieneData` | `src/rustc_span/hygiene.ts` (span-hygiene) | `SyntaxContext` branded number with `root()`; `HygieneData.new(edition)` |
| `DefId`, `LocalDefId`, `CrateNum`, `DefIndex`, `LOCAL_CRATE`, `CRATE_DEF_INDEX` | `src/rustc_span/def_id.ts` (span-hygiene) | per PORTING §5 interned handles |

Debug formats that the `parse` suite will check (match them exactly):
- `Span`: `file.rs:1:1: 1:33 (#0)` via the source map when present; `no-location (#0)` for dummy spans.
- `Symbol` inside `Ident` Debug: `main#0` (name + `#` + syntax context).
- `NodeId(4294967040)` (DUMMY_NODE_ID) — rustc_ast, not this wave.
